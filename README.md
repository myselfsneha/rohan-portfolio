## ◈ The Experience

A complete visual refresh of Rohan Pande's artist portfolio — built around oversized editorial typography, midnight earth tones, muted olive details, and subtle motion.

The idea is simple: let the music lead, give the visuals room to breathe, and make the entire experience feel connected.

## ◉ Design Language

| Element | Direction |
|:--|:--|
| **Atmosphere** | Midnight, earthy, cinematic |
| **Palette** | Deep charcoal, muted olive, warm cream, earthy brown |
| **Typography** | Expressive serif headlines paired with clean sans-serif text |
| **Interactions** | Scroll reveals, restrained hover transitions, responsive navigation |
| **Experience** | Responsive layouts and reduced-motion support |

No unnecessary visual clutter. No generic dashboard-style cards. Just music, imagery, typography, and a more intentional flow.

## 🚀 Run It Locally

```bash
git clone https://github.com/myselfsneha/rohan-portfolio.git
cd rohan-portfolio
npm install
npm run dev
```

Build and preview the production version:

```bash
npm run build
npm run preview
```
