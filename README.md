## 🌿 About the Project

This is Rohan Pande's artist portfolio, redesigned to bring his music, visuals, and creative journey together in one place.

The new direction uses a dark, earthy palette, oversized typography, subtle animations, and a more editorial layout. The focus is on making the music and imagery stand out without cluttering the experience.

🔗 **Explore it live:** [rohannpande.netlify.app](https://rohannpande.netlify.app/)

## 🎨 The Look & Feel

- 🌑 Dark backgrounds with earthy olive and warm cream accents
- ✍🏻 Expressive typography and spacious editorial layouts
- 🎬 Smooth scroll reveals and subtle hover interactions
- 📱 Responsive navigation and layouts for smaller screens
- ♿ Reduced-motion support and visible keyboard focus states

## 🚀 Run Locally

```bash
git clone https://github.com/myselfsneha/rohan-portfolio.git
cd rohan-portfolio
npm install
npm run dev
```

To create and preview a production build:

```bash
npm run build
npm run preview
```
