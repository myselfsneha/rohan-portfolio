## 02 — Inside the Experience

The portfolio isn't trying to squeeze an artist into a grid of generic cards. It's built as a sequence of spaces, each with its own role in the story.

| Chapter | What's inside |
| --- | --- |
| **The Introduction** | An expressive hero introducing Rohan and setting the visual tone. |
| **The Sound** | Spotify integration featuring *Junoon* and Rohan's artist catalogue. |
| **The Journey** | An editorial, timeline-inspired look at the creative journey. |
| **The Screen** | A featured YouTube video alongside existing photography. |
| **The Connection** | Direct links to Rohan's music, videos, and social presence. |
| **The Next Chapter** | A dedicated space for collaboration and project enquiries. |

The idea is simple: **let the work lead, let the design support it, and leave enough room for the personality to come through.**

---

## 03 — The Visual Language

A little less neon. A little more atmosphere.

The redesign leans into a warm, cinematic palette and editorial layouts, giving the content space to breathe.

| Element | Direction |
| --- | --- |
| **Palette** | Deep charcoal, muted olive, warm cream, and earthy clay |
| **Typography** | Expressive display lettering paired with quieter, readable text |
| **Composition** | Oversized headings, deliberate spacing, and varied section layouts |
| **Movement** | Subtle reveals, transitions, and hover details |
| **Experience** | Responsive layouts, keyboard focus visibility, and reduced-motion support |

The visual direction is deliberately restrained. The website should feel like *Rohan's space*, not a collection of effects competing for attention.

## 05 — Run It Locally

Want to explore the code or experiment with the interface?

You'll need Node.js and npm installed.

```bash
git clone https://github.com/myselfsneha/rohan-portfolio.git

cd rohan-portfolio

npm install

npm run dev
```

Vite will provide a local development URL in your terminal.

### Production build

```bash
npm run build
npm run preview
```

The build command creates the production bundle. The preview command lets you check that build locally.
